# Asados de la 70 — demo web

Propuesta de sitio responsive para **Asados de la 70**, con la carta organizada por categorías, ubicación en Belén, contacto y solicitud de reserva por WhatsApp.

## Ver en local

No requiere instalación ni dependencias. Desde la carpeta del proyecto:

```bash
python3 -m http.server 8080
```

Abre `http://localhost:8080`.

## Incluye

- Carta digital con 25 opciones, categorías y precios transcritos del menú compartido.
- Formulario que prepara una solicitud de reserva por WhatsApp al 324 476 2176. No registra datos en un servidor ni confirma disponibilidad automáticamente.
- Enlaces de llamada e indicaciones a Google Maps.
- Imágenes gastronómicas originales generadas para esta propuesta; no son fotografías verificadas del establecimiento.

## Datos de referencia

Dirección indicada: Cra. 70 # 12 - 05, Belén, Medellín, Antioquia.

Teléfono indicado: 324 476 2176. Se usa como enlace `tel:` y como destino de WhatsApp (`+57 324 476 2176`).

Los precios, nombres y marcas «NUEVO» provienen del texto del menú compartido. Confirma con el negocio la carta, precios, dirección exacta, datos de contacto, condiciones de reservas y las imágenes antes de presentar como sitio oficial.
